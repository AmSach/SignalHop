SignalHop

Peer-to-Peer Communication via Sound Waves

What if your phone could talk to another phone without WiFi, Bluetooth, or cellular?
Sound works everywhere. Every phone has a speaker and microphone.

🎧 Try Live Demo
FSK Modem Mesh Routing 18kHz Ultrasonic 500 sym/s

🔊 No Infrastructure

Earthquakes, hurricanes, conferences — when the internet is down, sound still works. It propagates through walls. No towers needed.

📡 Mesh Networking

Hop-by-hop routing with TTL. Your message travels peer-to-peer across the room or across a disaster zone.

🧠 AI Noise Cancellation

Spectral subtraction + CNN-based demodulator. Works in noisy bars, moving cars, or underground shelters.

📱 Cross-Platform

Python for server/ML. C++ for embedded (ESP32). JavaScript for browser demos. One protocol, everywhere.

The Protocol

Frame Structure:
[Preamble: 4 up-chirps] [Header: 41 bytes] [Payload: ≤256 bytes] [CRC32: 4 bytes]

Header Format:
  NETWORK_ID    : 12 bytes  ("SIGNALHOP_V1")
  Payload Length: 1 byte
  Sequence      : 2 bytes
  TTL           : 2 bytes
  Sender ID     : 8 bytes
  Reserved      : 16 bytes

CRC32 checksums header + payload for integrity verification.
